# Кадри у Visual Studio для суворої відповідності правилам

Надані скриншоти справжні, але зроблені у Linux із запущеним ASP.NET Core та браузером.
Вони не є знімками вікон Visual Studio. Якщо викладач вимагає саме цей редактор,
після відкриття solution у Visual Studio 2022 на Windows зробіть наведені кадри.

1. Відкрийте `ChumakovD_LR5.sln`, виберіть профіль `http`, виконайте Build Solution.
2. Відкрийте View → Terminal і виконайте `whoami`. Залишайте результат видимим на знімках коду.
3. Зробіть альбомні знімки `TodoItem.cs`, `DatabaseOptions.cs` разом із налаштуванням
   `ValidateOnStart` у `Program.cs`, двох нових методів у `TodoItemsController.cs`.
4. Запустіть API, відкрийте Swagger або головну сторінку, повторіть POST, batch і пошук.
   Використовуйте Id із нових відповідей POST.
5. Для помилки конфігурації тимчасово задайте `Database:Name = "abc"`, запустіть API,
   зніміть помилку виводу й поверніть `TodoList` перед наступними перевірками.
6. Замініть відповідні рисунки у звіті; залиште підписи, центрування і нумерацію.
   У розділі середовища зазначте фактичну версію Visual Studio та Windows.

Не підмінюйте результат `whoami` і не називайте браузерний перегляд коду вікном Visual Studio.

Проєкт опубліковано у відкритій гілці GitHub:
https://github.com/Dima808/ChumakovD_LR5/tree/codex/chumakov-lr5
Посилання можна передати викладачу для перевірки. Історія локальної генерації та доробок є в Git bundle.
